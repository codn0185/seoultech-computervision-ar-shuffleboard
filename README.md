# seoultech-computervision-ar-shuffleboard

컴퓨터비전 텀 프로젝트: AR로 구현한 Shuffleboard 게임

## 프로젝트 개요

웹캠 영상 위에 Shuffleboard 게임을 증강현실(AR)로 구현하여 상호작용하는 프로젝트입니다.

- Python 버전: `>=3.11, <3.13`
- 주요 기술: `OpenCV`, `MediaPipe`
- 패키지/실행 관리: `uv`

## 요구 사항

1. `Python 3.8 이상` 버전 설치
2. `uv` 설치

    ```bash
    pip install uv
    ```

## 빠른 시작

프로젝트 루트에서 실행합니다.

1) 의존성 설치 및 가상환경 동기화

    ```bash
    uv sync
    ```

2) 앱 실행

    ```bash
    uv run app
    ```
